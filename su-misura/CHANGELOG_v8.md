# Su Misura 店舗・本社システム v8 変更点（2026-11-24）

対象：`PV_SuMisura_HQ_Master_System_v8.html`（本社）／`PV_SuMisura_Shop_System_v8.html`（店舗）
※本社・店舗とも v8 に揃えてご利用ください。v7 で作成したJSON・ブラウザ保存データはそのまま読み込めます。

## 不具合修正
1. **2件目の新規カルテが1件目を上書きする** → 店舗の新規カルテ（仮番号 TEMP-）を本社で読み込むと、進行表の最大番号＋1で案件Noを自動採番。同じ案件Noに別のお客様が登録済みの場合は上書き前に確認を表示。「新規採番」ボタンを追加。
2. **ご成約ステータスが本社で空欄になる** → 文言を「03_ご成約済・お預り品発送準備」に統一。v7の「…発送待」は自動変換。
3. **お預り状況が店舗で空欄になる** → 店舗版に「本社受入検品完了・保管中」を追加。今後どちらかに選択肢が増えても空欄にならないよう、受信値を自動で選択肢に追加。
4. **写真が大きいと進行表に保存されない** → 画像を長辺1600px・JPEGに自動縮小（スマホ写真 約3〜10MB → 1MB未満）。容量不足時は古い案件の画像から外して保存し、その旨を表示。保存できなかった場合は「登録しました」と出さず警告を表示。
5. **前の案件の画像・コメント・金額が残る** → 案件の読込・切替時に毎回初期化してから反映（本社・店舗とも）。
6. **朝9時前は受付日が前日になる** → 日本時間で日付を取得。

## 細かな改善
- 店舗：本社回答の読込時に、仮番号（TEMP-）の重複行を自動整理。
- 店舗：本社の進行表を取り込む際は「置き換え」でなく「統合」。本社へ未送付の店舗案件は消えません。
- 本社：消費税0%の設定が正しく反映。お値引が合計額を超える場合は合計額までに調整して表示。
- 本社：進行表に本社の原価入力（単価・重量・工賃・追加項目・値引）を保存し、「開く」で復元。店舗へ出すファイルには含まれません。
- 本社：店舗共有用の進行表を「共有先店舗」で絞り込んで出力。他店のお客様情報を含めません（大阪高島屋店の引継案件は引継先店舗にも含まれます）。
- 本社：店頭の「リスク案内済み」チェックの状態を本社サマリーに表示し、往復でチェックが外れないよう修正。
- 店舗：「ご成約確定」は「リスク案内済み」チェックが入っていないと実行できないように変更。見積未着の場合は確認を表示。
- 店舗：進行一覧に削除ボタンを追加。
- 受信した画像データの形式を確認してから表示（不正なファイル対策）。
